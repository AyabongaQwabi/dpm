# ServicePros Authority Building Plan

Date: 2026-08-05
Skills used: seo-authority-builder, seo-content, seo-geo

## Authority Score

Current estimated authority readiness: 62/100.

ServicePros has meaningful trust foundations: public policy pages, provider verification explanations, review surfaces, profile pages, a contact page, provider terms, customer pricing, and a clear marketplace model. The gaps are mainly around entity corroboration, expert authorship, original evidence, and public proof that other organizations recognize or reference the platform.

## Immediate Trust Repairs

1. Resolve public contact placeholders

The contact page still contains visible TODO-backed claims for:

- person responsible for the site
- reason-specific email routes
- response time commitment
- POPIA Information Officer details

These are trust-critical. Do not scale SEO traffic into unresolved legal/contact copy.

2. Populate Organization identity

Add confirmed:

- legal name
- trading name
- logo URL
- primary email
- primary phone if available
- postal or operating address if publishable
- social/profile URLs
- POPIA Information Officer contact

3. Add editorial ownership

Create a simple editorial footer for informational pages:

```txt
Reviewed by the ServicePros marketplace team. Last updated: {Month YYYY}.
```

For legal/policy pages, use:

```txt
Published by Namoota Technology. Last updated: {Month YYYY}.
```

## Link and Citation Strategy

### Foundational citations

Target profiles where business information can be consistent:

- Google Business Profile
- LinkedIn company page
- Facebook page
- Instagram profile
- Crunchbase or startup ecosystem profile if relevant
- South African business directory entries
- CIPC-linked public company information where appropriate

### Partner citation opportunities

Ask platform partners to link to their ServicePros partner page or provider profile from:

- their official website
- case study pages
- services pages
- client resources pages
- social profiles

Preferred anchor text:

- `ServicePros platform partner`
- `listed on ServicePros`
- `{service category} partner on ServicePros`
- `ServicePros provider profile`

### Provider backlink program

Give listed providers a simple badge or text link they can place on their site:

```html
<a href="https://servicepros.co.za/providers/{provider-slug}">View our verified ServicePros profile</a>
```

Use `rel="noopener"` for UX/security. Do not require `nofollow`; provider profile links are legitimate citations when placed editorially.

## Original Evidence Assets

Add one or more of these reusable proof blocks:

- `ServicePros marketplace snapshot`: published providers, active cities, service categories, verified profiles, completed bookings if available.
- `Provider verification breakdown`: counts by Contact, Google, CIPC, FICA.
- `Average response experience`: only if measured.
- `Popular service categories`: based on real browsing or booking data.
- `City coverage`: real list of cities with published providers.

Each statistic needs:

- source table or report
- last updated date
- whether it is public, internal, or estimated

## Suggested Author Profiles

Use real people only. If individual ownership is not ready, publish as the ServicePros marketplace team.

Template:

```txt
{Name} is part of the ServicePros marketplace team, working on provider onboarding, marketplace trust, and local service discovery in South Africa. Their work focuses on making provider profiles easier to compare and helping small service businesses get found online.
```
